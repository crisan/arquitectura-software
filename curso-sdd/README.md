# Curso: Specification-Driven Development (SDD)

Curso práctico para aprender a diseñar software partiendo de especificaciones antes de escribir una sola línea de código.

## ¿Qué aprenderás?

- Qué es SDD y por qué reduce errores y retrabajo
- Cómo modelar un dominio con lenguaje ubicuo
- Cómo escribir especificaciones ejecutables con Gherkin
- Cómo pasar de especificación a tests y de tests a código
- Cómo aplicarlo en una API REST real con OpenAPI

## Módulos

| Módulo | Tema |
|--------|------|
| [01 - Fundamentos](./01-fundamentos.md) | Qué es SDD, diferencias con TDD y BDD |
| [02 - Modelar el dominio](./02-dominio.md) | Lenguaje ubicuo, entidades, bounded contexts |
| [03 - Escribir especificaciones](./03-especificaciones.md) | Gherkin: Given / When / Then |
| [04 - De spec a código](./04-implementacion.md) | Ciclo completo: spec → test → código |
| [05 - SDD con APIs REST](./05-api-spec.md) | API-first con OpenAPI |
| [06 - Ejercicio completo](./06-ejercicio.md) | Sistema de transferencias bancarias de principio a fin |

## Prerequisitos

- Conocimientos básicos de programación (el curso usa Python en ejemplos)
- Entender qué es una API REST (ver [Diseño-APIs.md](../Diseño-APIs.md))

## Cómo seguir el curso

Sigue los módulos en orden. Cada uno termina con un **ejercicio** pequeño que prepara el siguiente. El módulo 06 integra todo en un proyecto real.
